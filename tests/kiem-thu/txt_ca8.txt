CA KIỂM THỬ TC08 — SQL SERVER NGỪNG HOẠT ĐỘNG / KHÔNG THỂ KẾT NỐI

Mục đích
Xác nhận ứng dụng xử lý lỗi cơ sở dữ liệu an toàn, không bị crash và cho phép thử lại sau khi dịch vụ hoạt động trở lại.

Điều kiện trước
- Tài khoản thử nghiệm đã tồn tại.
- Có thể dừng và khởi động lại dịch vụ SQL Server trên máy thử nghiệm.
- Chỉ thực hiện trên môi trường kiểm thử được phép; không dừng SQL Server dùng chung hoặc phục vụ dữ liệu thật.

Dữ liệu kiểm thử
- Tên đăng nhập: test_ca1_001
- Mật khẩu: giá trị đúng đã dùng để đăng ký test_ca1_001 ở TC01

Các bước thực hiện
1. Dừng dịch vụ/instance SQL Server dùng bởi ứng dụng.
2. Mở hoặc quay lại màn hình Đăng nhập, nhập thông tin tài khoản hợp lệ.
3. Nhấn Đăng nhập và ghi nhận thông báo; quan sát nút và trạng thái ứng dụng.
4. Khởi động lại SQL Server và chờ dịch vụ sẵn sàng.
5. Thử đăng nhập lại với thông tin hợp lệ.

Kết quả mong đợi
- Khi SQL Server ngừng: hiển thị thông báo thân thiện, ví dụ “Không kết nối được cơ sở dữ liệu. Hãy thử lại.”
- Không hiển thị stack trace, tên lớp ngoại lệ hoặc chi tiết kết nối nội bộ cho người dùng.
- Ứng dụng không bị crash/treo; nút thao tác được bật lại sau lỗi.
- Khi SQL Server hoạt động lại: người dùng có thể thử lại và đăng nhập thành công.

Minh chứng
Kèm hai ảnh trong báo cáo nhóm: (1) lúc SQL Server dừng và ứng dụng báo lỗi; (2) sau khi khởi động lại SQL Server và đăng nhập thành công. Chỉ ghi ĐẠT sau khi chạy thử thực tế.
